DAYCUBE local capture

This starter sends the active tab's URL, title, scroll position and viewport size to your local receiver. It does not collect page text, screenshots or webcam video.

Capture is disabled by default. URLs and titles can still contain private information. Configure exclusions before enabling.

The token is kept in this browser's local extension storage. Add the extension ID to DAYCUBE_EXTENSION_ID in your .env and restart the receiver. The toolbar badge reads ON while enabled and ERR when delivery fails.
